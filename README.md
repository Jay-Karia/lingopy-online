# LingoPy Online

An online code editor for LingoPy - write, run, and test your code directly in the browser.

# LingoPy

_"Write Python in your native tongue "_

[LingoPy](https://github.com/shaunbenedict/LingoPy)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up environment variables:
   ```bash
   MASTER_TOKEN=your_token_here
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Usage

1. Select your language from the dropdown
2. Write your code in the editor
3. Click "Run" to execute
4. View the output below

## Tech Stack

- **Next.js 15** - React framework
- **Jotai** - State management
- **Tailwind CSS** - Styling
- **Quill** - Rich text editor
